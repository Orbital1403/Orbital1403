## grgaGrow — From soil measurements to useful information

A soil-monitoring and garden-management project combining a cloud
application with planned ESP32 and RS485 sensor integration.

The application brings together measurement history, weather,
garden records and alerts, with separate public views and a private
owner workspace.

My contribution includes defining the garden workflow, deciding
how readings and uncertainty should be presented, planning hardware
integration and checking software behaviour.

One important design rule: an old reading must not look like a
current measurement. Missing or unreliable data should remain
visible and should not support a watering recommendation.

**Status:** Cloud application online. The public demo uses simulated
readings. Physical sensor integration and the complete device-to-cloud
path still require verification.

[Project notes, application and hardware plan](https://gordangrgic.com/projects/grgagrow/)

## Our Laundry — Check before carrying the laundry downstairs

A shared-laundry project exploring how residents can understand
machine status before visiting the laundry room.

My focus is defining meaningful states: a running machine, a finished
cycle and collected laundry are different facts.

**Status:** Interactive demo with simulated states.
Live integration is in development.

[Explore Our Laundry](https://gordangrgic.com/projects/our-laundry/)
